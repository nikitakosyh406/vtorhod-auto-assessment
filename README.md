# ВТОРХОД

Учебный некоммерческий React-прототип сервиса оценки и выкупа повреждённых автомобилей.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```powershell
npm install
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Страницы

- `/#home` — главная, оригинальная вращаемая 3D-схема, FAQ.
- `/#process` — описание будущего процесса.
- `/#login` и `/#register` — интерфейсы входа и регистрации.
- `/#account` — кабинет, открывается после перехода через форму входа.
- `/#application` — ознакомительная форма заявки, доступна из кабинета.
- `/#chat` — окно диалога без отправки и автоматических ответов.

Вход и регистрация переключают только состояние интерфейса в текущей вкладке. Реальных пользователей нет, пароль не сохраняется, сетевых запросов авторизации нет. После перезагрузки доступ закрывается. В localStorage хранится только выбор темы. Фотографии остаются в памяти страницы; заявка никуда не отправляется. Кнопка в форме проверяет заполнение, не рассчитывая стоимость.

## 3D

Основной автомобиль — выбранная пользователем модель **BMW M5 G90 2024 | www.vecarz.com**, автор **vecarz (@heynic)**, Sketchfab:
https://sketchfab.com/3d-models/bmw-m5-g90-2024-wwwvecarzcom-b2dd13e63c2649c3be90da30e6670a46

Лицензия модели — **CC Attribution-NonCommercial-ShareAlike 4.0**:
https://creativecommons.org/licenses/by-nc-sa/4.0/

Модель подключена официальным Sketchfab Viewer API без скачивания и перепубликации архива. На странице сохранены ссылки на автора и лицензию. Изменения представления: нейтральные графитово-серые материалы, мягкое освещение без пересвета, фон, камера и разнесение доступных узлов. Материалы модели используют отдельную палитру linear RGB; синие цвета технической схемы не применяются к PBR-кузову. Пользователь подтвердил исключительно учебное некоммерческое назначение.

Для внешнего просмотрщика нужен интернет. Модель содержит примерно 791 тысячу треугольников и может загружаться заметно дольше на слабых устройствах; кнопка «Чертёж» открывает лёгкую локальную схему. Если Sketchfab недоступен, предлагается перейти к чертежу.

«Разнести детали» открывает авторскую общую схему внутренних узлов. Вкладка «Мотор и КПП» показывает силовой блок крупнее, а «Кузов G90 · оригинал» разносит доступные группы исходной модели через Viewer API (колёса, подвеску, капот, стекло, части кузова и интерьера). Матрицы исходных узлов сохраняются для сборки обратно. В исходной модели не обнаружены отдельные узлы двигателя и коробки, поэтому они обозначены отдельной учебной схемой.

`src/carGeometry.js` содержит оригинальную процедурную модель в духе BMW M5 G90: кузов с колёсными арками, длинный капот, решётка, оптика, остекление, зеркала, дверные линии, спойлер, выхлоп и многоспицевые колёса. Это художественная интерпретация, не точная CAD-модель BMW.

`src/CarCanvas.jsx` рисует её через Three.js / WebGL 2 с буфером глубины. SVG используется для сетки и подписей. Поддерживаются мышь, касание и стрелки клавиатуры, разнесение деталей и сброс ракурса. Перерисовка выполняется при изменении ракурса, размера или темы; постоянного цикла анимации нет. Цвета синхронизированы с CSS-переменными. При размонтировании освобождаются геометрия, материалы и renderer.

`src/carInternals.js` содержит самостоятельные учебные сборки: V8 с впуском, турбинами и шкивами; радиатор и патрубки; корпус КПП с рёбрами; кардан и дифференциал; подрамники, рычаги, амортизаторы, пружины, тормозные диски и суппорты; пол, батарейный блок, выпуск; кресла, задний диван, панель приборов, консоль и руль. Они не извлечены из модели vecarz и не являются заводскими чертежами BMW.

## Дизайн

Светлая и тёмная темы, адаптивные стили, EB Garamond и IBM Plex Mono. Шрифты загружаются из Google Fonts; при недоступной сети используются Georgia и Courier New.

Figma: https://www.figma.com/design/uhUIzH7EhksiA9hBtpfQg8

Файл содержит 28 основных экранов: 7 маршрутов × Desktop 1440 / Mobile 390 × Light / Dark. Основные фреймы имеют имена маршрута, размера и темы. В файле также остались вспомогательные захваты, поскольку лимит Figma Starter остановил финальную очистку и визуальную проверку. Полное пиксельное соответствие пока не подтверждено.

`atlas.html` — служебная страница только для локальной подготовки макетов; в production-сборку не включается. Параметры `?route=...`, `?theme=light|dark`, `?view=member` служат для просмотра макетов; это не механизм авторизации. Динамическое подключение Figma capture активируется только специальным служебным hash-параметром.

## Границы версии

Нет C# API, регистрации пользователей, анализа фото/VIN, интеграции с Exist, расчёта предложения и отправки сообщений. Подключение бэкенда — следующий этап. В текущей версии нет выдуманных оценок или ответов менеджера.

Пользователь отдельно разрешил загрузку исходников и приватную публикацию в Sites. Конфигурация проекта находится в `.openai/hosting.json`; права доступа следует сохранять приватными.

В Figma сохраняется лимит Starter, поэтому исправления расположения и подписей пока не применены. `design/repair-figma-layout.js` содержит подготовленную операцию для официального Figma `use_figma` после восстановления доступа. Она удаляет вспомогательные захваты, размещает 28 экранов в четырёх колонках и добавляет русские подписи. Новую модель ещё нужно перенести в четыре главных экрана Figma.

## Проверка

- Production-сборка Vite проходит.
- В браузере проверены переходы главная → регистрация → кабинет → форма заявки.
- Проверено заполнение VIN, марки/модели и года: кнопка проверки показывает сообщение без отправки.
- Проверены светлая/тёмная темы, мобильное меню, переключение FAQ, вращение модели с клавиатуры и режим разнесённых деталей.
- В окне менеджера поле принимает черновик, кнопка отправки отключена.
- В проверенных переходах нет ошибок консоли. На настольном экране горизонтального переполнения нет.
- Визуально проверены настольная главная, мобильная главная и чат, настольная форма в тёмной теме.
- `review/home-desktop.jpg` — сохранённый вид стартового экрана.
