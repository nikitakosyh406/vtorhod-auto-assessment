# ВТОРХОД

Мой учебный проект — сайт для оценки битых автомобилей и их выкупа на запчасти.

Пока сделал только фронтенд на React: главную страницу, вход и регистрацию, личный кабинет, форму заявки и окно чата. Ещё есть 3D-модель BMW, просмотр деталей, светлая и тёмная темы. Сайт адаптирован под телефон.

Настоящей авторизации и оценки автомобиля пока нет. Дальше планирую подключить бэкенд на C#.

## Как запустить

Нужен Node.js. В папке проекта выполнить:

```bash
npm install
npm run dev
```

После запуска открыть адрес из терминала. Для 3D-модели нужен интернет.
